Connect your agent

Choose the agent running on your computer. Install its Kubik integration before connecting.

Install the Kubik plugin from npm on your OpenClaw computer first. It also prints the address Kubik needs when OpenClaw is not on this Wi-Fi.

Open on your computer: github.com/pfrankov/kubik

On that computer, install and enable the channel:

openclaw plugins install openclaw-kubik
openclaw channels add --channel kubik --enable
openclaw channels status --probe

The last command prints the Kubik address (kubik://…) for the Server address field below.

When Kubik shows a pairing code, run the approval command on its screen on your OpenClaw computer.

Create your personal key at Muse Gadgets. After Wi-Fi connects, pair in the Muse app on your phone. No computer or server needed. Replies appear as text.
