# Звуки Кубика

Офлайн-генератор всех UI-звуков. Чистый JS, без зависимостей, результат детерминирован (seed от имени звука).

```sh
node tools/sfx/generate.mjs          # всё
node tools/sfx/generate.mjs tap pet  # только имена с этими префиксами
node tools/sfx/verify.mjs            # проверки через ffmpeg + out/sheet.png
```

Результат:
- `firmware/assets/sfx/<name>.pcm`: s16le, моно, 24 кГц, прошивка играет как есть;
- `firmware/assets/sfx/manifest.json`: `name, file, ms, group, variant, variants, lufs, true_peak_dbtp, gain_notes, design`;
- `tools/sfx/out/<name>.wav`: превью для прослушивания (в git не идут).

Варианты `name_1..N` образуют группу `group`, прошивка выбирает случайный (не тот же, что в прошлый раз).
Кроме того, каждое проигрывание берёт одну из четырёх тональностей (−3, −1, 0, +2 полутона; тоже не ту же, что в прошлый раз): звук сдвигается целиком, так что интервалы, ритм и огибающая остаются его собственными, а два раза подряд одинаково он не звучит. Исключение: `volume_*` (там высота и есть уровень).

## Правила кита
- Кубик — мишка, а не пищалка: весь кит на октаву ниже (`OCTAVE = −1`, так что `N('C5')` звучит как C4), «голос» (форманты) как у более крупного тела (`VOICE`), шумы темнее (`DARK`).
- Все ноты только из мажорной пентатоники (C D E G A), `N('X5')` падает на чужой ноте. `KEY` в начале файла транспонирует весь кит (5 = фа мажор).
- Вес низкой ноты несёт октава: ниже ~300 Гц динамик почти не излучает, поэтому у калимбы, маримбы и «блупов» заметная вторая гармоника.
- Синтез: калимба (1x + 2.76x + 5.4x, верхние гаснут быстрее), маримба, FM-колокол (ratio 3.5, индекс затухает), блипы и «блупы» с огибающей высоты, пузырьки, полосовой шум (whoosh, мурчание с AM ~25 Гц), вибрато, короткий реверб Шрёдера (6–22 % wet).
- Динамик: HPF 180 Гц (4-й порядок), мягкий LPF 5 кГц, партиалы выше 8 кГц не синтезируются. Внутри 48 кГц, затем FIR-децимация до 24 кГц.
- Атака ≥ 2 мс, хвост уходит в ровный ноль; первый и последний сэмпл = 0.
- Громкость: −20 LUFS (BS.1770, фильтры как в ffmpeg ebur128), `think_*` и `setup_wait` тише остальных (−28 и −27). True peak ≤ −3 dBTP; если пик мешает, мягкий лимитер берёт до 3 дБ, дальше звук просто делается тише.
- Клипы короче 400 мс ebur128 меряет как −70 LUFS, поэтому `verify.mjs` меряет их зацикленными (громкость самого клипа).

## Как поправить звук
Каждый звук описан в `generate.mjs` через `def({ name, ms, rev, fade, target, idea, draw })`; `max` задаёт жёсткий предел длины (`listen_start` ≤ 160 мс, `latch_start` ≤ 180 мс и т. д.). После правки: `generate.mjs`, `verify.mjs`, посмотреть `out/sheet.png` и послушать wav.
