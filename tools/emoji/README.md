# Приватный атлас Apple Emoji

Генератор использует установленный на Mac `Apple Color Emoji` через CoreText.
Он не копирует системный шрифт и не включает изображения Apple в исходники.
Сгенерированные бинарный атлас, preview и provenance сохраняются только вне
репозитория; файлы получают права `0600`.

```sh
python3 tools/emoji/build-apple.py --output /absolute/private/path/apple-emoji.bin
python3 tools/emoji/build-apple-color.py --output /absolute/private/path/apple-emoji-color.bin
python3 tools/emoji/test-atlas.py
python3 tools/emoji/test-color-atlas.py
```

По умолчанию загружается официальный `emoji-test.txt` Unicode 17.0 с проверкой
закреплённого SHA-256. `--unicode-source /path/emoji-test-17.0.txt` использует
сохранённую копию с той же обязательной проверкой. Данные Unicode не содержат
изображений Apple; условия источника: <https://www.unicode.org/terms_of_use.html>.

Каждая последовательность должна составлять один grapheme cluster и одну
ячейку Apple Color Emoji. CoreText может собирать её из перекрывающихся слоёв;
это допустимо. Подстановка другого шрифта, отсутствующий глиф и разложение
ZWJ-последовательности на отдельные emoji-ячейки отклоняются. Отчёт перечисляет
неподдержанные последовательности, не заменяя их похожими картинками.

Растр — 32×32, один бит на пиксель: чёрный контур исходной alpha-маски,
тёмные детали и ограниченное упорядоченное растрирование средних тонов.
Это монохромное представление для термопринтера, не цветной отпечаток.

`atlas.py` задаёт формат KEMJ v1: заголовок 32 байта, отсортированный UTF-8
индекс с записями по 12 байт и растры по 128 байт, MSB first. Пределы:
8192 последовательности, 64 UTF-8 байта на ключ, общий размер 2 МиБ.
Синтетические тесты проверяют формат без распространения Apple artwork;
на macOS дополнительно проверяются настоящие составные glyphs и отказ
от подстановки другого шрифта.

Для цветного экрана используется отдельный KEMC v1: 15 адаптивных цветов
RGBA плюс прозрачный и 4-битные индексы, 576 байт на глиф. Сглаживание
сохраняет частичную alpha; KEMJ остаётся прежним. Полный контракт:
[docs/emoji-assets.md](../../docs/emoji-assets.md).
