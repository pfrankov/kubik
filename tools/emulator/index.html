Screen Lab

Real firmware screens. Temporary data.
No device or agent needed.

Drag the character in any direction. Tap native controls. Hold Speech for Sound. Hold a voice preview to hide/show controls. BOOT returns; hold BOOT for Settings. Events: swipe history, tap details; BOOT returns. Agent events: Next or KEY advances the example. KEY changes the voice preview signal or ends Live. PWR toggles the simulated screen.

QR codes and pairing codes are demo fixtures. This preview does not measure radio, panel timing or physical audio.
