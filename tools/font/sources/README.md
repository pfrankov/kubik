# Font source

These four original TTF files come from the Google Fonts `ofl/ptsans` and
`ofl/ptsanscaption` directories at the `main` revision fetched 2026-09-29.
Their shared SIL Open Font License 1.1 is in `licenses/OFL-PT-Sans.txt`.
`tools/font/gen-font.swift` rasterizes a subset into firmware bitmap glyphs.
