# Исторические сценарии: не применять к текущей прошивке

## Исторические сетевые сценарии — требуют актуализации

Следующие сценарии BLE относятся к прежней реализации и не являются критериями
текущей настройки через Wi-Fi AP.

### Настройка сети по Bluetooth

| Действие | Ожидаемый результат |
|---|---|
| Сканировать QR в ESP BLE Provisioning на iPhone или Android | Приложение подключается к устройству и устанавливает защищённую сессию |
| Подключиться с неверным кодом подтверждения | Передача настроек отклоняется |
| Выбрать сеть и передать правильный пароль | После получения IP сеть сохраняется единой записью; устройство перезапускается, Bluetooth выключается |
| Передать неверный пароль или отсутствующую сеть | Приложение получает ошибку; можно повторить попытку, прежняя сохранённая сеть остаётся |
| Включить устройство без сохранённой сети | QR появляется автоматически; Bluetooth ожидает телефон |
| Потерять Wi-Fi менее чем на 30 секунд | Устройство пытается переподключиться; QR не появляется |
| Wi-Fi недоступен более 30 секунд | Автоматически открывается Bluetooth-настройка |
| Потерять сервер при работающем Wi-Fi | QR не появляется; показывается состояние отсутствия связи с сервером |
| Запустить с сохранённой сетью при подключённом USB-мосте | Wi-Fi получает IP, все обработчики запускаются, `welcome` переводит приложение онлайн; Wi-Fi и сервер имеют отдельные диагностические статусы |
| Не подключать телефон к QR | Настройка остаётся открытой; прежние параметры сети сохранены |
| Вернуть роутер, пока открыт QR и телефон не подключён | Проверка сохранённой сети раз в 30 с восстанавливает подключение и убирает QR без перезаписи настроек |
| Подключить телефон по BLE | Новые фоновые попытки подключения к прежней сети не запускаются до отключения телефона |
| Нажать BOOT в режиме настройки | Перезапуск проверки сохранённой сети; при её отсутствии QR появляется снова |
| Перезапустить устройство после успешной настройки | Используются новые SSID и пароль; адрес сервера, токен, громкость и имя сохранены |
| Обновить старую прошивку с сохранённой сетью | SSID и пароль переносятся в единую запись, старые ключи удаляются после успешной записи |

Проверка сохранения и миграции: `python3 tools/test-settings.py`.
Проверка восстановления сети: `python3 tools/test-wifi.py`.
Проверка цикла настройки: `python3 firmware/sim/provision_test.py`.
Проверка сервиса на устройстве без передачи пароля:
`python3 tools/check-ble.py --idf "$IDF_PATH" --name PROV_XXXXXX`
(нужны `bleak`, `cryptography`, `protobuf`; имя указано на экране).
BLE использует NimBLE и Security 1 с новым случайным кодом подтверждения для каждого входа.
Пароль и код подтверждения не печатаются в журнал.

## Адрес OpenClaw и выбор соединения

| Действие | Результат |
|---|---|
| Запустить USB-мост без `--server` и открыть `http://127.0.0.1:18791/` | Видны ID устройства, адрес и отдельные состояния Wi-Fi, OpenClaw и выбранного канала; сохранённый токен не раскрывается |
| Ввести полный адрес канала и токен, нажать «Сохранить и подключить» | Пара сохраняется атомарно, устройство перезапускается; подтверждение подключения появляется только после ответа сервера |
| Изменить адрес, оставив поле токена пустым | Существующий токен сохраняется |
| Передать недопустимый адрес или получить ошибку записи NVS | Команда возвращает ошибку, рабочая пара в памяти не заменяется; интерфейс не сообщает об успешном сохранении |
| Обновить прошивку со старыми отдельными ключами адреса и токена | Пара переносится в единую запись, затем старые ключи удаляются |
| Подключить USB к зарядному устройству | Наличие кабеля не считается доступом к серверу; используется Wi-Fi |
| Отключить USB при работающем Wi-Fi | Кубик самостоятельно подключается к сохранённому адресу; отсутствие сервера отличается от отсутствия Wi-Fi |
| Запустить мост с недоступным сервером | Heartbeat моста не переводит Кубик на неработающий USB-канал |
| Восстановить сервер USB-моста | После подтверждённой авторизации выбирается USB; прямое соединение освобождается |
| Получить старый USB-пакет после переподключения | Пакет с предыдущим номером сессии отбрасывается |
| Указать `wss://` | Перед подключением синхронизируется время; сертификат сервера проверяется |
