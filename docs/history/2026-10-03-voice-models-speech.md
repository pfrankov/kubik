# Голосовые модели и передача речи Tess

## Изменение

- Agent → Input/Replies сразу открывают каталог моделей; выбранная модель
  отмечена. Промежуточные страницы удалены, BOOT возвращает в Agent.
- Realtime/GPT-Live используют общий голосовой выбор для ввода и ответа.
  Модель и контекст агента сохраняются. Выбор привязан к аккаунту, устройству
  и ключу сопряжения в приватном атомарном файле состояния плагина.
- Короткие native PCM-фрагменты объединяются в ограниченной серверной очереди.
  Отправка ограничена 1200 мс неподтверждённой речи, включая пакеты в сети.
  Неизменный progress не продлевает ожидание: остановка наступает
  через **пять секунд** без продвижения при заполненном окне.
- Прошивка выделяет полный буфер 1500 мс либо отказывается от воспроизведения.
  Для пользовательского хода память TLS резервируется до VAD; при отказе
  ручная запись не начинается, экран предлагает повторить KEY.
- Во время короткой сетевой паузы Tess не перезапускает анимацию начала ответа.

- ESP-IDF 5.5.1: собрана и записана только Tess, app-раздел 0x20000.

- Физическое меню: прямой Input/Replies, смена и возврат исходной модели,

## Уточнения приёмки

- Запись по KEY начинается параллельно с подключением к голосовому SDK.
  Ошибка SDK может прийти после открытия АЦП; физическая проверка требует
  закрытия ADC/RX и прекращения чтения после ошибки, без ответа и делегации.
  Отдельный C-тест проверяет более ранний `input_end`: захват не открывается.
- При смене тестового адреса устройство перезагружается. Опрос ждёт его
  в пределах таймаута и повторяет только чтение, не команду изменения настроек.

## Границы доказательства

- В двух предварительных прогонах стенда возник таймаут применения Live
  после Realtime. Причина не установлена; последующие полные paced/burst
  прогоны прошли. Это не доказательство исправления причины того таймаута.
- Реальные платные ответы моделей и права аккаунта на все варианты каталога
  не проверялись. Каталог берётся из установленного SDK и конфигурации.
- Акустическая фраза Hi Tessa не проигрывалась. Проверялось только управление
  слушателем при смене режима/меню/сна. Таймаут VAD проверен на host с заданным
  сигналом; отсутствие речи в комнате не используется как воспроизводимый тест.
- Счётчики кадров не доказывают отсутствие tearing на физической панели.
- Сборка Plush пропущена по прямому указанию пользователя.
