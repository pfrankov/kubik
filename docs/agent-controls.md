# Модели, голос и управление агентом

Английский путь покупателя: [настройка речи](buyer/START.html#voice),
[адрес подключения без обязательного домена](buyer/START.html#address),
[запрос агенту для подготовки установки](buyer/START.html#assistant).
OpenClaw поддерживает Classic, Realtime и GPT Live; текущий адаптер Hermes —
Classic через платформу внутри существующего Hermes Gateway; используются его штатные STT/TTS. Realtime/Live в Hermes 0.21.4 недоступны; [прямое подключение](hermes.md).

Кубик работает с одной сессией вашего агента. Модель агента независима от голоса.
В Classic распознавание и озвучка настраиваются раздельно; в Realtime/GPT-Live
для ввода и ответа используется одна голосовая модель. Ключи остаются на сервере.

## На устройстве

После первого подтверждённого подключения открывается гайд из четырёх экранов:
знакомство, ввод по KEY, способ ответа и реальные настройки. Подсказки адаптируются
к текущим STT/TTS и громкости. Настроенные провайдеры используются автоматически;
если распознавания или озвучки нет, экран объясняет, что включить на сервере.
`Check again` перечитывает возможности без записи и вызова модели. Это проверка
конфигурации, а не оплачиваемая проба провайдера и не изменение его ключей.

Каждый шаг показывает один компактный заголовок с иконкой и инструкции по левому
краю. Верхняя строка отведена прогрессу и `Skip`, нижняя — основному действию.

`Open settings` завершает гайд и открывает меню. `Skip` также сохраняет
прохождение; после перезапуска гайд не появляется снова. Чтобы пройти заново,
удерживайте BOOT и нажмите `Guide`. Сети, агент, ключ сопряжения, модель и громкость
при этом сохраняются. Незавершённый гайд можно продолжить вручную с начала;
после перезапуска он будет предложен снова. KEY, PWR и свайп вверх закрывают гайд,
он также закрывается после двух минут без касаний; это не отмечает его завершённым.
Полный сброс очищает отметку прохождения вместе с остальными настройками.

Короткий BOOT возвращает к предыдущему шагу, а с первого — в Settings,
не отмечая гайд завершённым.

Удерживайте BOOT, затем нажмите `Agent`. Обзор показывает `Agent model`
и `Voice` с текущим голосовым режимом. Модель агента выбирается отдельно:
два крупных варианта на странице, короткий BOOT возвращает к обзору.

`Voice` сразу показывает три режима: `STT`, `Realtime`, `GPT Live`.
В STT (`classic` в конфигурации) речь сначала распознаётся, затем агент отвечает;
`Recognition` и `Speech` открывают отдельные каталоги STT и TTS.
У Realtime/GPT Live одна модель отвечает за ввод и речь: после выбора режима
сразу открывается её каталог. Нажатие уже выбранного режима открывает его настройки.
Недоступный режим помечен `Set up on your agent`; ключи настраиваются на host.
BOOT возвращает на предыдущий уровень: модели → режимы → Agent → Settings;
для STT между моделями и режимами есть страница Recognition/Speech.

Выбор режима и моделей сохраняется на host по аккаунту, устройству и ключу
сопряжения. Модели каждого режима запоминаются отдельно. Это не меняет другие
Кубики, модель, контекст и инструменты агента. `channels.kubik.voice.mode`
задаёт начальный режим; сохранённый выбор Кубика имеет приоритет над ним.
Каталог обновляется при открытии; `Refresh` повторяет проверку без записи,
вызова модели или платного пробного запроса.
Изменение модели считается сохранённым
после подтверждения сервера. Во время записи и ответа менять модель нельзя.
Ошибку связи или прав экран показывает явно; повторное открытие обновляет данные.
Движение пальца отменяет выбор: оно не меняет модель, громкость или яркость
скрытого экрана. При сохранении другие варианты и стрелки временно недоступны.

Выбор модели агента меняет только сессию этого Кубика; голосовой выбор сохраняется
отдельно для аккаунта, устройства и ключа сопряжения, переживая переподключение.
Оба выбора не меняют другие чаты, задания и глобальную модель по умолчанию.
Адаптер без возможности менять модель
показывает её текущее состояние без выдуманного списка вариантов.

Громкость управляет выводом автоматически:

| Условие | Ответ |
| --- | --- |
| Громкость ≥ 20 и TTS настроен | Голосом |
| Громкость < 20 | Текстом |
| TTS отсутствует или не смог синтезировать ответ | Текстом |

Точные коды и адреса агент может явно вывести на экран через `[[show]]…[[/show]]`.
Это работает и при голосовом ответе. Распознавание STT нужно только для ввода:
если оно отключено, Кубик не записывает запрос, но продолжает принимать текстовые
уведомления и позволяет выбирать модель. Для голосового ввода сначала настройте
STT на сервере; текстовый чат самого агента продолжает работать независимо.

Plush включает микрофон только для записи по KEY. Tess также локально распознаёт
**Hi Tessa** на включённом главном экране при готовых связи и STT, затем записывает
команду до паузы. Модель ищет Tessa; префикс Hi не проверяется, срабатывание без него возможно. До активации PCM не отправляется
серверу. В настройках, гайде, при ответе и с погашенным экраном слушатель выключен.
Фоновые разговоры не поворачивают персонажа и не будят спящий Кубик.

## В OpenClaw

Один раз настройте доступ провайдера и разрешённые модели в OpenClaw.
Каталог моделей агента берётся из OpenClaw, выбор сохраняется в сессии устройства.
Агент тоже может менять модель своей сессии через инструмент `session_status`
с параметром `model`, если этот инструмент разрешён в его политике.
Попросить «переключись на …» можно голосом; доступность операции зависит
от инструментов и прав агента. Экран выбора подтверждает изменение непосредственно.

В текстовой сессии того же Кубика доступны встроенные команды:

```text
/models
/model provider/model -s
/status
/think low
/fast on
```

`-s` фиксирует модель только в текущей сессии. `model=default` через
`session_status` возвращает модель по умолчанию. Уровни размышления и fast mode
поддерживаются не всеми моделями; OpenClaw проверяет их доступность. Не рассчитывайте,
что распознавание буквально запишет произнесённый слеш: экран выбора удобнее.

Обычный STT настраивается через `tools.media.audio` и `tools.media.models`
(записи `tools.media.models` с явным `capabilities: ["audio"]`). В OpenClaw 2026.9.7
`tools.media.audio.models` не участвует в выборе исполняемой модели; перенесите
такие записи в общий `tools.media.models`. Выбор Recognition сохраняет именно настроенную
запись, включая её параметры, и не меняет распознавание других чатов. Обычный TTS использует `tts.provider` и настройки
этого провайдера; `channels.kubik.tts` задаёт голос именно для Кубика.
Список распознающих моделей не совпадает со списком моделей агента.
Для нативного голоса каталог приходит из зарегистрированного провайдера SDK
с учётом режима. TTS предлагает модели только настроенного провайдера, если
тот поддерживает модельные overrides; переключения провайдера в меню нет.
Для обычного STT доступны явно настроенные аудиомодели; автоматический/local STT
и отдельный `gpt-live-transcribe` показывают состояние без выдуманного каталога.
Список означает поддержку провайдера и наличие настройки доступа, а не проверку
оплаченного доступа аккаунта к каждой модели. Удалённый вариант не заменяется
другой моделью автоматически: выберите доступный в меню.
Наличие API-функции ещё не означает наличие настроенного голосового провайдера.
Экран сообщает состояние настройки; действительность ключа и доступность сети
окончательно подтверждаются реальным запросом.

## Почему ответ может ждать

Путь состоит из распознавания, работы агента, синтеза и передачи звука.
В журнале Кубика фазы измеряются отдельно без текста запроса и ключей.
Первое наблюдение на текущем сервере: 14 727 мс STT, 15 024 мс до первого блока
агента, 3 812 мс TTS; суммарно 33 563 мс после отпускания кнопки.
Это один ход, а не средняя скорость.

После включения потокового STT и PCM на том же устройстве, Wi-Fi и сессии
`openai/gpt-6.1-sol` с размышлением `low` проверен полный ответ: STT 629 мс,
агент 13 124 мс, TTS до первого PCM 1 623 мс; первый аудиопакет отправлен
через 15 376 мс после отпускания кнопки. Устройство подтвердило воспроизведение
3 801 мс речи без разрывов. Это один успешный замер, а не гарантия времени
ответа; основную задержку теперь создаёт модель агента. Заголовок `speech begin`
в журнале устройства приходит до PCM и не измеряет начало слышимого звука.

Поток готовых блоков агента уже работает. Короткое первое предложение можно
начать озвучивать, пока агент продолжает ответ. Модель с долгим размышлением
всё равно может долго готовить первый текст; выбор более быстрой модели и
поддерживаемого режима размышления меняет именно эту часть задержки.

В OpenClaw 2026.9.7+ потоковое распознавание для Кубика включается один раз:

```sh
openclaw config set channels.kubik.voice.liveTranscription true
```

Этот режим использует уже настроенный **API-ключ OpenAI**, модель
`gpt-live-transcribe` и русский язык из `channels.kubik.voice.language`.
Авторизация OAuth для текстовой модели не заменяет API-ключ аудиопровайдера.
`OPENAI_API_KEY` в окружении службы используется для аудио даже тогда, когда
текстовая модель авторизована через OAuth; без него нужен профиль OpenAI с API-ключом.
Сокет открывается только на время записи; после результата или отмены закрывается.
При ошибке доступа режим сообщает ошибку, не отправляя тот же запрос повторно
другому распознавателю. Для штатного файлового STT настройте значение `false`;
его модель и провайдер берутся из конфигурации OpenClaw.

OpenAI TTS отдаёт PCM потоком; провайдер, голос и тембр берутся из конфигурации,
а модель — из сохранённого выбора Кубика, если он задан, иначе из конфигурации.
ElevenLabs использует потоковый метод SDK с тем же правилом выбора. Остальные провайдеры
с поддержкой PCM используют свой обычный метод; другой провайдер при ошибке
не выбирается. Эти возможности не требуют менять модель самого агента.

Realtime transcription — потоковый STT для режима `classic`.
Отдельные нативные режимы `voice.mode: realtime` и `voice.mode: live` используют
голосовую модель как интерфейс к прежнему агенту: его контекст, выбранная модель
и инструменты сохраняются. Настройка и ограничения описаны в
[Realtime/GPT-Live](native-voice.md). Режим по умолчанию — `classic`.
Реальные разговоры проверялись на конкретном стенде; их время не гарантирует
скорость или доступ к модели у другого аккаунта. Проверка каталога бесплатна,
а новый разговор с провайдером может оплачиваться.

Проверки с имитацией провайдеров доказывают, что аудио уходит на STT до
отпускания кнопки, а первый PCM ответа приходит до завершения синтеза.
Они не гарантируют доступ конкретного аккаунта к модели или реальный выигрыш
при его сети и нагрузке; для этого измеряется один и тот же живой путь.

## Другие агенты

[Agent SDK](agent-sdk.md) описывает, как подключить любой агент одним модулем:
`connect` и `reply`. Для выбора на Кубике адаптер дополнительно реализует пару
`modelOptions(device)` / `selectModel(device, model)`: возвращает настоящий каталог,
сохраняет выбор по идентификатору устройства и подтверждает его повторным чтением.
Без этой пары выбор недоступен. Платформа Hermes использует модель и голос из самого Hermes; модели меняют в Hermes, отдельный host не нужен.

Независимый host показывает настройки своих STT/TTS отдельно от модели агента.
Его мастер запрашивает совместимый API, модели и ключ; наличие ключа означает
настроенную возможность, а не подтверждённую доступность платного сервиса.
Этот независимый host предназначен только для собственных адаптеров; Hermes использует свои настройки речи напрямую.

Официальные справочники: [Realtime transcription](https://developers.openai.com/api/docs/guides/realtime-transcription)
и [GPT-Live с отдельным агентом](https://developers.openai.com/api/docs/guides/live).

Выбор режима и голосовых моделей хранится в `kubik/voice-models.json` внутри каталога
состояния OpenClaw: максимум 128 идентичностей, без ключей провайдеров.
Файл закрыт правами 0600 и обновляется атомарно. Повреждённый файл вызывает
ошибку настроек, а не молчаливый сброс выбора. Для резервной копии сохраняйте
его вместе с остальным состоянием плагина.


В GPT Live KEY или Hi Tessa у Tess включает непрерывный разговор. Пауза не
завершает его; после ответа микрофон открывается снова. KEY или тап завершает
Live, открытие меню и сон также закрывают его. Статус микрофона показан на
главном экране. [Границы и сроки](native-voice.md#границы-текущей-реализации).

## Громкость речи и интерфейса

Основной ползунок Settings регулирует речь агента. Удерживайте его 0,8 секунды
без движения: Sound показывает отдельные Speech и Interface. Короткий BOOT
возвращает в Settings. Speech действует на STT, Realtime и GPT Live; Interface
на звуки интерфейса и персонажа. Ноль заглушает только выбранную группу.
Оба значения сохраняются при закрытии Settings и переживают перезапуск.
Interface имеет обычный максимум без дополнительного усиления; Speech независим.
После обновления Interface наследует прежнюю громкость. Полный сброс задаёт 70
для обеих групп. Порог голосового ответа 20 относится только к Speech.
Речь больше не ослабляется общей шкалой кодека; её отдельное усиление ограничивает пики.

## Muse

[Нативный Muse](muse.md) подключается без host. SDK для C6 принимает голосовую
заметку и возвращает текст; STT доступен при соединении, TTS/Realtime/GPT Live — нет.
Recognition и Agent показывают Managed by Muse без выбираемых моделей.
SDK key вводится только в мастере на телефоне; ключи аккаунта не видны в меню.

## Events on Kubik

In Settings, tap the battery indicator five times within four seconds to reveal
**Events**. Closing Settings hides it again. The journal shows the last 16 events processed by the device since
restart. Swipe up/down or use Older/Newer; tap an entry to read its message excerpt
and reaction description. BOOT returns one level. **Overlay on home** saves an
optional translucent event panel over the character. It does not change agent or
voice settings. This is a local event history, not a full server trace. See
[event history and previews](events.md) for previews and limits.

## Fully dark screen

Press PWR to wake the screen. Touch, motion, BOOT and KEY are ignored while it is
fully dark. A nonempty text reply or a current voice reply can wake it automatically;
connection changes, agent status, emotions and background activity cannot. A dimmed
but visible screen brightens on touch; holding or dragging keeps it active.
