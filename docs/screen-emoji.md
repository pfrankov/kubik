# Apple Emoji в ответах на экране

Текстовые ответы Hermes и OpenClaw используют один экранный путь на C6 и S3.
Цветные Emoji берутся из приватного атласа владельца на host агента. Обычный
текст остаётся в штатном шрифте Кубика. Системный шрифт Mac и изображения Apple
не включаются в публичный репозиторий, прошивку или комплект.

Атлас `apple-emoji-color.bin` создаётся на Mac из установленного Apple Color Emoji;
генератор и формат описаны в [инструкции по глифам](emoji-assets.md).
На OpenClaw файл находится в каталоге состояния аккаунта Kubik, рядом с TLS;
на Hermes — в `<HERMES_HOME>/kubik/`. Это отдельный цветной файл для экрана;
`apple-emoji.bin` содержит чёрно-белые глифы для печати.

## Экран и память

Флаг, оттенок кожи, keycap и последовательность с ZWJ измеряются и переносятся
целиком. Цветной глиф занимает квадрат 32×32 в design-координатах и компонуется
в нативные пиксели панели. Страница содержит до шести строк и четырёх разных
Emoji; повторения используют один глиф. Когда встречается пятый новый символ,
текст продолжается на следующей странице. Обычный ответ без Emoji сохраняет
прежнее разбиение. Потоковое дополнение текста сохраняет текущую страницу.

Кубик хранит только четыре глифа текущей страницы. Сцена получает собственную
неизменяемую копию до освобождения mutex; получение следующего глифа или страницы
не меняет данные уже рисуемого кадра. Весь атлас в прошивку не загружается.
Нет повторной отправки запросов, очереди на переподключение или вызовов модели
для получения изображений. Неполученный за три секунды или отсутствующий глиф
показывается одним пустым квадратом; составной символ не распадается на части.

## Протокол

Устройство объявляет `screen_emoji: 1` в `hello`. После подтверждённого `welcome`
оно запрашивает нужные последовательности текущей страницы:

```json
{"t":"emoji_get","id":7,"seq":["😀","❤️","👩‍💻"]}
```

`id` — ненулевой `uint32` поколения страницы; `seq` содержит от одной до четырёх
уникальных полных последовательностей, каждая не более 64 байт UTF-8. Host
разрешает только символы из последнего реально отправленного этому Кубику
текстового ответа. Запрос не даёт доступа к чужой сессии или произвольному файлу.
Для каждого символа приходит отдельный ответ:

```json
{"t":"emoji","id":7,"seq":"😀","data":"<base64: 576 bytes>"}
```

`data` — канонический base64 цветного глифа KEMC или JSON `null`, когда глиф
недоступен. Массив содержит 16 цветов RGBA8888 и 512 байт индексов 4 bpp.
Проверяются точный размер, палитра, последовательность, поколение и сессия;
данные копируются до освобождения входного JSON. Ответ другой страницы,
отменённого ожидания или старого соединения игнорируется. `shown` по-прежнему
подтверждает установку текста карточки, а не окончание асинхронной загрузки глифов.

Host ограничивает обращения к атласу двумя запросами в секунду с burst 4;
при превышении отвечает `null` без обращения к диску. Ручное быстрое листание
не разрывает разговор. Отсутствующий приватный файл не меняет работу обычного
текста, озвучки или принтера.
