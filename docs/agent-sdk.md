# Адаптер: свой агент для Кубика

Контракт адаптера — текст: распознанная реплика на входе, ответ агента на выходе.
Host ведёт голосовой тракт PCM s16le mono 24 кГц и кодек IMA ADPCM. При реализации
собственного транспорта используйте текущий протокол v5
из [описания протокола](protocol.md) и обновляйте host вместе с прошивкой.

**Адаптер** — один локальный ESM-модуль. Через него Кубик подключается к любому
агенту: HTTP API, официальный SDK, локальный процесс или WebSocket. Прошивка
не знает, какой это агент.

OpenClaw и Hermes используют плагины внутри своих Gateway: [OpenClaw](../openclaw-kubik/README.md), [Hermes](hermes.md). Отдельный `kubik-agent-host` предназначен только для собственных ESM-адаптеров.

Host уже делает связь с устройством, TLS, сопряжение, распознавание, озвучку,
очередь речи и уведомления. Адаптер делает только работу агента: проверить
настройки, выполнить запрос и вернуть текст ответа.

Модуль выполняется как обычный локальный код внутри процесса host. Песочницы нет.

## Что адаптер не делает

- Не получает звук с микрофона и не подставляет свой синтез в динамик. На входе
  текст реплики, на выходе текст ответа. Голос — отдельная настройка host.
- Не показывает вопрос с кнопками. Такой разбор есть только у канала OpenClaw.
  Свой агент может произнести вопрос текстом; следующий KEY придёт новым ходом.
- Не получает готовую историю от host. Передавайте `device.id` как ключ сессии
  подключённому агенту; хранение истории и выполнение инструментов остаются у агента.
- Не отменяет уже начатый прогон, когда пользователь перебивает речь. Инструменты
  и запись в историю агента могут завершиться. Обрывается только озвучка.
- Отдельный host не запускается без `OPENAI_API_KEY`. Это ключ распознавания и
  озвучки host, не ключ агента. Пока ключа нет, процесс serve не стартует.

Меню устройства использует цели `agent`, `mode`, `voice`, `stt`, `tts`.
В публичном Agent SDK методы `modelOptions`/`selectModel` работают только
с `agent`. Голос принадлежит host. Штатный независимый host предлагает STT
(`classic`), а Realtime/GPT Live показывает недоступными. Настроенные STT/TTS
видны в Recognition/Speech; каталог пуст, изменение модели на устройстве
не поддерживается. Провайдеры и модели задаются в мастере host.
OpenClaw дополнительно реализует выбор режима и голосовых моделей.
Для собственного host нейтральный контракт перечисления, доступности,
сохранения и подтверждения описан в [протоколе](protocol.md#agent-controls-and-speech-capabilities-062).
Реализуйте голос на host, не добавляя OpenClaw-зависимостей в прошивку или
текстовый адаптер агента. Ключи провайдеров устройству не передаются.

## Запуск host

Нужен Node.js 24.16+ в ветке 24.x или 26.1+. Из каталога комплекта:

```sh
npm install ./openclaw-kubik-0.6.2.tgz
export OPENAI_API_KEY='your-voice-provider-key'
npx kubik-agent-host setup
npx kubik-agent-host serve
```

В исходниках вместо `npx kubik-agent-host` используется `node tools/agent-host.mjs`.
Мастер печатает команды с полным путём к Node, поэтому они работают и без
локального `node_modules/.bin` в PATH. На Windows их запускают в PowerShell,
на macOS и Linux — в обычной оболочке.

Мастер спрашивает путь к вашему ESM-файлу, поля этого файла, проверяет
`connect` и сохраняет настройки. В поле типа `env` записывается **имя переменной**,
не её значение. Host должен оставаться запущенным.

Кубик и компьютер должны быть в одной сети. Пустой адрес на устройстве —
автообнаружение, либо `kubik://хост:18790`. Порт TCP по умолчанию 18790.
UDP-обнаружение всегда слушает 18790, даже если в мастере выбран другой TCP-порт.
Пустой ответ на `Bind address` включает все интерфейсы и при повторной настройке
очищает прежнюю привязку. Чтобы сохранить конкретный адрес, введите его снова.
Когда на экране появится код:

```sh
npx kubik-agent-host pair-list
npx kubik-agent-host approve CODE
```

Одобряйте только ожидаемое устройство. Одобрение привязано к его id и отпечатку
ключа. Неизвестный ключ сам не одобряется. Файлы host лежат в
`~/.config/kubik-agent-host` или в `--state-dir PATH`: настройки, сопряжение,
ключ TLS и очередь уведомлений. Каталог 0700, файлы 0600, запись атомарная.
Используйте отдельный каталог для host: при запуске его права устанавливаются
в 0700, поэтому общий каталог других приложений для `--state-dir` не подходит.
Каталог нужно сохранять при обновлении: удаление ключа TLS меняет сервер,
которому доверяет Кубик.

Громкость от 20 и доступная озвучка дают голос. Меньшая громкость или сбой
синтеза дают текстовую карточку. Это уже делает host, адаптер голос не выбирает.

## Минимальный адаптер

Сохраните файл как `my-agent.mjs`, в мастере выберите свой адаптер и укажите путь.

```js
import { defineAdapter } from 'openclaw-kubik/agent-sdk';

export default defineAdapter({
  id: 'my-agent',
  label: 'My agent',
  setup: [],
  async connect() {},
  async reply({ transcript }) {
    return `You said: ${transcript}`;
  },
});
```

`defineAdapter` собирает объект, который host вызывает так:
`connect`, затем `start`, если он есть, затем ходы, затем `close`. Сами
`dispatch` не пишите: его делает обёртка. Уже готовый модуль с собственным
`dispatch` host по-прежнему загружает; новый адаптер пишите через `reply`.

| Метод | Когда вызывается | Что делает адаптер |
|---|---|---|
| `connect({ config, env, log, signal })` | При проверке в мастере и при запуске host | Проверяет настройки, создаёт клиент; `config` содержит только значения `setup`. Ошибка отклоняет запуск. |
| `start({ events, log })` | После успешного `connect` и запуска слушателя; в мастере не вызывается | Запускает необязательные фоновые подписки. |
| `reply({ device, transcript, turnId, signal, isCurrent, events })` | На распознанную реплику | Возвращает текст или поток законченных фраз. Историю разделяет по `device.id`. |
| `close()` | После проверки, при остановке или ошибке запуска | Освобождает клиент и подписки, в том числе после частично выполненного `connect`. |

`connect` и `reply` обязательны; `start` и `close` добавляйте по необходимости.
В `connect` параметр `log` передаётся при запуске host; проверка в мастере
передаёт только `config`, `env` и `signal`. Если нужен журнал в обоих случаях,
объявите `connect({ config, env, signal, log = () => {} })`.
Сигнал из `connect` действует на весь срок жизни подключения адаптера к агенту,
общий для всех Кубиков. Различия между остановкой host и перебиванием речи
описаны в [отмене](#отмена).

## Как перенести любого агента

Меняются четыре места, контракт один:

1. **Где агент.** В `connect` проверьте адрес, создайте клиент SDK или убедитесь,
   что локальная команда существует.
2. **Чем он авторизуется.** Секрет читается из окружения по имени из настроек.
3. **Какой текст говорить.** `reply` получает реплику и возвращает ответ.
4. **Какой это разговор.** Всегда передавайте агенту `device.id`, чтобы устройства
   не делили историю.

`reply` получает `{ device, transcript, turnId, signal, isCurrent, events }`.
`device.id` — id Кубика. Рядом могут быть `name`, `fingerprint`, `fw` и `volume`.
Верните строку, массив законченных фраз или async-итератор таких фраз.
Пустой ответ ничего не произносит. Не возвращайте ошибку текстом: бросьте
`Error` с коротким сообщением без секретов, адресов и тела ответа провайдера.
Кубик показывает «Try again» и не читает текст ошибки. Само сообщение пишется в журнал host.

Фраза ставится в очередь речи сразу. Возврат из `reply` не ждёт конца звука.
Не дробите ответ на отдельные токены: одна фраза или несколько законченных фраз.
Host сам убирает из речи markdown, ссылки, код и эмодзи.

В тексте работают те же пометки, что и у OpenClaw:

- `[[happy]]` и имена `neutral`, `happy`, `joy`, `love`, `sad`, `angry`,
  `surprised`, `confused`, `sleepy`, `thinking`, `wink`, `shy`, `proud`.
  Имя становится эмоцией персонажа в момент этой фразы и вслух не читается.
- `[[show]]код или адрес[[/show]]` показывается на экране и не произносится.

## Готовый HTTP-пример

Для обычного JSON API скопируйте проверенный пример из пакета и замените в нём
два запроса: проверку в `connect` и ход в `reply`.

```sh
cp node_modules/openclaw-kubik/src/agent-sdk/examples/http-json.js ./my-agent.mjs
export MY_AGENT_TOKEN='your-agent-key'
npx kubik-agent-host setup
```

Пример рассчитан на такой сервер, но ваш агент может иметь другие пути:

| Запрос | Успешный ответ |
|---|---|
| `GET /health` | `{"ok":true}` |
| `POST /turn` с `{"session":"DEVICE_ID","text":"вопрос"}` | `{"text":"ответ"}` |

Оба запроса отправляют `Authorization: Bearer <MY_AGENT_TOKEN>`. Удалённый адрес
должен быть HTTPS; localhost может быть HTTP. Пример ограничивает проверку 5 с,
ход 30 с, тело 64 КиБ, ответ 8192 символами и 8 одновременными запросами.
`close` обрывает незавершённые запросы. Чужой URL, токен и тело ошибки в журнал
не попадают.

Тот же каркас подходит для Chat Completions, своего SDK и локальной команды.
Меняется только тело `connect` и `reply`. Фрагменты ниже — поля того же объекта
`defineAdapter`, не отдельные файлы.

Клиент SDK:

```js
let client;
async connect({ config, env, signal }) {
  client = createClient({ token: readSetupEnv(config, 'tokenEnv', env) });
  await client.ready({ signal });
},
async reply({ device, transcript, signal }) {
  return client.complete({ session: device.id, text: transcript, signal });
},
close() { client?.close(); },
```

Локальный процесс: скопируйте исполняемый пример и укажите в мастере абсолютный
путь к программе агента. При настройке проверяются обычный файл и право исполнения;
ссылка на такой файл допустима, каталог отклоняется. Программа получает `--session DEVICE_ID`, читает реплику
из stdin и пишет один текстовый ответ в stdout; stderr не переносится в журнал.
Shell не используется.

```sh
cp node_modules/openclaw-kubik/src/agent-sdk/examples/local-process.js ./my-agent.mjs
npx kubik-agent-host setup
```

Пример ограничивает весь ход 30 с, вывод 64 КиБ, ответ 8192 символами и восемью
одновременными процессами. Ошибка запуска, stdin, завершения или переполнение
не превращается в частичный успешный ответ. Остановка host обрывает дочерние
процессы и закрывает их потоки ввода/вывода. Таймаут действует и после выхода
основного процесса, если его потомок удерживает stdout открытым.
Сигнал, уже прерванный до запуска, не создаёт процесс. Команда должна
выполнять работу сама: эти ограничения не управляют её потомками и службой,
которой она могла передать запрос.

WebSocket устроен так же: сокет открывается в `connect`, ход уходит в `reply`,
сокет закрывается в `close`, а `signal` обрывает ожидание при остановке host.

`defineAdapter` ограничивает один ответ 8192 символами (UTF-16) и 512 фрагментами,
включая пустые. Превышение завершает чтение потока с ошибкой до постановки
лишнего фрагмента в очередь; уже переданные фразы не отменяются. Предпочитайте
завершённые фразы вместо отдельных токенов.

Эти ограничения относятся к выводу. Таймаут запросов и число одновременно
работающих ходов задаёт адаптер: `defineAdapter` не ограничивает их за него.
Перебитый ход агента продолжает работу, поэтому новые ходы могут пересекаться
со старыми. В HTTP- и process-примерах предел — восемь запросов и 30 с на ход.

Очередь отдельного ответа или уведомления держит не более 32 ожидающих
фрагментов плюс один в синтезе. Host обрабатывает потоки последовательно.
`defineAdapter` сам ждёт свободного места перед чтением следующей фразы.
В собственном `dispatch` обязательно пишите `await speak(text)`; `false` означает,
что речь этого хода уже отменена. Не отправляйте фразы параллельно или без `await`.
При отключении либо сбое рабочего цикла ожидание освобождается. Ошибка рабочего
цикла закрывает соединение, чтобы устройство могло подключиться заново.

Поток фраз:

```js
async *reply({ device, transcript, signal }) {
  for await (const phrase of client.stream(device.id, transcript, { signal })) yield phrase;
}
```

## Отмена

`isCurrent()` становится ложным, когда пользователь перебил речь, ход сменился
или устройство отключилось. Поздний текст после этого произносить нельзя.
`defineAdapter` проверяет это сам и не ставит в очередь ответ устаревшего хода.
Поток дочитывается без озвучки, даже если речь перебили до возврата из `reply`.
Это позволяет агенту завершить работу и освободить ресурсы своего итератора.

`signal` при этом **не** обрывается. Не отменяйте запрос к агенту только потому,
что `isCurrent()` стал ложным.

`signal` обрывается при `close`, начале нового `connect` или ошибке текущего
`connect`. На `signal` вешайте свои fetch, сокет и дочерний процесс. Мастер
вызывает `connect` и затем `close`, в том числе после неудачной проверки.
Фоновые подписки в этой проверке не запускайте: для них есть `start`.
`close` должен терпеть частично прошедший `connect`.
После неудачного `connect` его `signal` обрывается; `dispatch` не вызывает
`reply` до следующего `connect`. При остановке host не запрашивает следующий
фрагмент и закрывает итератор через `return()`, даже если `reply` вернул его
после остановки. Уже начатые ожидания внутри `reply`, `next()` и `return()`
должны сами учитывать `signal`: host не может завершить произвольный код адаптера.

## Настройки мастера

`setup` — массив не длиннее 32 полей. Ключи уникальны. У поля есть `key`,
`label`, `type`, необязательные `required` (только `true` или `false`) и `default`.
Значение по умолчанию проходит ту же проверку, что и введённое в мастере.

- `string` — до 1024 символов, либо `maxLength` от 1 до 2048.
- `integer` — необязательные границы `min` и `max`.
- `boolean` — да или нет.
- `env` — имя переменной. Значение читает `readSetupEnv(config, key, env)`.

`maxLength` разрешён только у `string`, `min` и `max` — только у `integer`.
Другие свойства, в том числе опечатки вроде `maxLenght`, отклоняются при загрузке
адаптера. Значения из мастера также не могут содержать неизвестные ключи.

`id` адаптера: строчная латиница, цифры и дефис, до 40 символов, с буквы.
`key` поля — строка до 40 символов, с маленькой латинской буквы, затем латиница
любого регистра или цифры. `id` и `key` обязательны; другие типы не приводятся
к строке. `label` — непустая строка до 80 символов. Поле, чьи ключ или подпись похожи на
token, password, secret или API key, обязано иметь тип `env`. Лишние поля
настроек отклоняются. Не пишите в журнал пароли, заголовки авторизации и сырые
тела ошибок провайдера.

## Модель на устройстве

Реализуйте оба метода или не добавляйте ни одного. Если указан только один,
адаптер не проходит проверку при загрузке. Когда этих методов нет, выбор модели
скрыт; host показывает только состояние своего распознавания и озвучки.

```js
async modelOptions(device) {
  return {
    model: await client.currentModel(device.id),
    models: [{ id: 'your-model-id', label: 'Fast model' }],
  };
},
async selectModel(device, id) {
  await client.saveModelForConversation(device.id, id);
},
```

Возвращайте только выбираемые модели: не больше 128 id, id до 160 байт UTF-8,
подпись до 80 байт, без управляющих символов. `model` — текущий id или пустая
строка. Адаптер сам сохраняет выбор для этого устройства, не меняя глобальную
модель агента. Host не сохраняет его за адаптер: он отбрасывает id вне каталога
и перед подтверждением читает выбор обратно.
Кубик и host ждут этот запрос 8 секунд. Каталог, запись и повторное чтение
должны завершиться внутри этого срока. Таймаут показывает ошибку, но не
откатывает уже сделанную запись; следующее чтение показывает то, что реально
сохранилось. До завершения самого запроса новый запрос этого Кубика получает
`busy`, в том числе после таймаута или переподключения. Это не даёт старой
записи перезаписать более новый выбор. Другие устройства могут выбирать модели
независимо. Адаптер должен ограничить время собственных запросов: таймаут
интерфейса не отменяет работу его хранилища. Во время разговора устройство выбор
не принимает.
Модели Hermes меняются в самом Hermes; его нативная платформа не использует этот ESM-мастер.

## События и уведомления

`start({ events, log })` вызывается после запуска слушателя. Тот же `events`
приходит в ход. Остановите источники в `close`. После остановки host, в том
числе после неудачного старта, методы `events` бросают ошибку.

- `events.activity(deviceId, { own, other }, ttlMs)` — снимок деятельности.
  Срок по умолчанию 30 с, допустимо 1–60 с, не больше 128 устройств. Категории:
  `thinking`, `tool`, `coding`, `web`, `deploy`, `build`, `concierge`,
  `compacting`, `stall` или пустая строка.
- `events.cron({ running, next }, ttlMs)` — число идущих задач и секунды до
  ближайшей одноразовой (`-1`, если её нет). Срок до 60 с. Пока источник жив,
  снимок нужно обновлять. Просроченный снимок гаснет сам. Это пассивный индикатор,
  он не будит экран. Для важного сообщения, в том числе напоминания, вызывайте `events.notify`.
- `await events.notify(deviceId, text, { signal })` — важное сообщение
  пользователю, не длиннее 4096 байт UTF-8. Возвращает состояние доставки или очереди.
  Одобренный спящий Кубик хранит сообщение, пока устройство его не подтвердит
  или пока не истечёт очередь. Неудача не разрешает слать его снова без границы.

Очередь host: 8 сообщений на устройство, 128 всего, срок 24 часа. Сеть, которой
нет, доставку не обещает. Голос подтверждается после полного воспроизведения,
текст — после установки последней карточки. Если часть уведомления озвучена,
а часть показана текстом, нужны оба подтверждения. При разрыве связи до них
сообщение сохраняется; частично полученный ответ может повториться.

## Hermes

Используйте [платформу внутри Hermes Gateway](hermes.md); отдельный host и Responses API не нужны.

## Встраивание в свой процесс

Если процесс уже есть, host можно не запускать командой:

```js
import { createAgentHost } from 'openclaw-kubik/agent-sdk';

const host = await createAgentHost({ stateDir, config, adapter, env, log });
await host.close();
```

`config` содержит `version: 2`, `listener: { port: 18790 }`, `voice` и
`adapter: { id, setup }`. Для отдельного компьютера проще команда `serve`.

`voice` хранит `baseUrl`, `transcribeModel`, `ttsModel`, `voice`, `language`.
Мастер спрашивает все пять значений; язык — двухбуквенный код (`en`, `ru`).
Ключи остаются в переменных окружения, а не в JSON. `readHostConfig()` асинхронна:
при чтении старого файла v1 она под блокировкой атомарно переносит `voiceBaseUrl`
в v2 с прежними моделями, голосом и языком; listener и adapter сохраняются.
Некорректный старый файл не перезаписывается. Рецепт запуска с отдельным
защищённым env-файлом относится только к собственным ESM-адаптерам.
Host печатает полный `kubik://IP:PORT` только для доступных IPv4 своего bind;
дома можно оставить адрес пустым и использовать обнаружение.

## Проверка

Из каталога `openclaw-kubik`:

```sh
node --test test/agent-adapter-example.test.js test/agent-process-example.test.js test/agent-sdk*.test.js
```

Затем из корня репозитория: `python3 tools/accept.py`. Для своего адаптера
проверьте отказ и очистку `connect`, два разных устройства, порядок фраз,
перебитую речь, таймаут, слишком большой ответ, остановку host во время запроса,
запись и обратное чтение модели, повторную доставку уведомления после
переподключения. До платного провайдера используйте mock. Эти проверки не
доказывают ключи, задержку и инструменты настоящего агента: этот путь проверяется
отдельно.

### Automatic Tess capture

The shared host handles `ptt.automatic` and turn-scoped `cancel` before the adapter.
Adapters receive the same transcription/agent calls as manual KEY recording;
no wake-word model, audio gate or VAD belongs in an adapter. An abandoned turn
must not dispatch a late transcription. See [the wire contract](protocol.md).

## Нативный Muse

Muse на ESP32 использует отдельный нативный транспорт, а не этот host SDK.
[Руководство](muse.md) описывает настройку без компьютера и ограничения.
`muse_backend` нормализует события в callbacks `link_handlers_t`; `muse_noise` владеет
одной TLS/Noise-сессией, `muse_pair` реализует штатное сопряжение приложения Muse.
Внутренние JSON-события Кубика не отправляются в Muse как host-протокол.
Новый нативный провайдер требует отдельного клиента своего документированного API,
проверки RAM/flash и возможностей; название в мастере само по себе не создаёт интеграцию.
