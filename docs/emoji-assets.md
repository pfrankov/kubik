# Приватные Apple Emoji

Исходники Кубика содержат генераторы и проверяемые форматы атласов, но не сам
Apple Color Emoji и не извлечённые картинки. Атласы создаются из системного
шрифта владельца на Mac и устанавливаются в приватное состояние его агента.
Пути к ним не задаются моделью. Копирование системного шрифта в прошивку или
публичный комплект не требуется; этот документ не предоставляет прав на artwork.

## Генерация

```sh
python3 tools/emoji/build-apple.py --output /absolute/private/path/apple-emoji.bin
python3 tools/emoji/build-apple-color.py --output /absolute/private/path/apple-emoji-color.bin
python3 tools/emoji/test-atlas.py
python3 tools/emoji/test-color-atlas.py
```

Нужны macOS, Swift и установленный `Apple Color Emoji`. Python использует только
стандартную библиотеку. Данные последовательностей берутся из официального
`emoji-test.txt` Unicode 17.0 с проверкой закреплённого SHA-256; для сохранённой
копии используется `--unicode-source /path/emoji-test-17.0.txt`. Варианты с VS16,
ZWJ, флагами и оттенками кожи проверяются как целые последовательности.

Генератор допускает только Apple Color Emoji, один grapheme cluster и одну
типографскую ячейку. Некоторые пары Apple рисует перекрывающимися слоями;
они поддерживаются. Подстановка другого шрифта, отсутствующий глиф или распад
неподдержанного ZWJ на отдельные ячейки дают явный отказ вместо похожей картинки.
Provenance JSON записывает версии и хеши Unicode, шрифта и атласа, количество
поддержанных/отклонённых последовательностей. Файлы получают `0600`, атлас
заменяется атомарно. Сгенерированное artwork должно оставаться вне репозитория.

## Общая структура

Все целые числа little endian. Заголовок — 32 байта:

| Смещение | Поле |
| --- | --- |
| 0 | 4 байта magic: `KEMJ` или `KEMC` |
| 4 | version, `u32`, только 1 |
| 8 | edge, `u32`, только 32 |
| 12 | count, `u32`, от 1 до 8192 |
| 16 | index offset, `u32`, только 32 |
| 20 | keys offset, `u32`, `32 + 12 × count` |
| 24 | payload offset, `u32`, выровнен на 4 байта |
| 28 | точный размер файла, `u32` |

Индекс содержит `count` записей по 12 байт: абсолютное смещение UTF-8 ключа
(`u32`), абсолютное смещение растра (`u32`), длина ключа (`u16`) и reserved
(`u16`, только 0). Ключ — 1–64 UTF-8 байта без NUL/управляющих символов.
Записи уникальны и строго отсортированы по UTF-8 байтам; ключи идут подряд,
после них не более трёх нулевых байтов выравнивания. Растры фиксированного
размера идут с начала payload; одинаковые изображения могут делить смещение.

## KEMJ: печать

Один растр — 128 байт, 32×32 по одному биту, строки сверху вниз, MSB first,
1 означает чёрную точку. Максимальный файл — 2 МиБ. Генератор сохраняет
тёмные детали, чёрный контур исходной alpha-маски и ограниченное упорядоченное
растрирование средних тонов. Это чёрно-белое представление для термопринтера.

## KEMC: цветной экран

Один растр — 576 байт:

- Первые 64 байта: 16 записей RGBA8888, **straight alpha**, по 4 байта.
  Индекс 0 — `00 00 00 00`. Неиспользуемые записи нулевые; запись с нулевой
  alpha не содержит ненулевых RGB. Индексы используемых непрозрачных или
  частично прозрачных цветов — 1–15.
- Следующие 512 байт: 32×32 индексов по 4 бита, строки сверху вниз,
  старшая половина байта — левый пиксель. Пиксель не ссылается на пустую
  запись палитры, кроме прозрачного индекса 0.

Максимальный файл — 8 МиБ. Палитра подбирается отдельно для каждого глифа
детерминированным взвешенным median cut: до 15 цветов плюс прозрачный.
Признаки используют premultiplied RGB и alpha; сами записи сохраняют
straight RGBA. Полностью непрозрачные пиксели не усредняются с краями,
а частичная alpha остаётся доступна для сглаживания на любом фоне.
Чёрно-белый KEMJ не заменяется цветным KEMC и не выводится вместо него.

Тесты форматов используют синтетические пиксели без Apple artwork. На macOS
дополнительно проверяются настоящие составные глифы и отказ от подстановки.
