# Muse напрямую с Кубика

Вариант без Kubik host: телефон настраивает Кубик, затем ESP32-C6 общается с Muse
по Wi-Fi. Компьютер для подключения не нужен. Нативная интеграция экспериментальная:
на Кубике проверен запуск режима привязки и Bluetooth-стека без ошибок выделения
памяти. Сопряжение с текущим приложением Muse и ответ облачного агента ещё не
подтверждены.

## Подключение с телефона

1. Установите приложение Muse и войдите в свой аккаунт. Убедитесь, что Muse отвечает
   в приложении. Создайте личный SDK key в
   [Muse Gadgets](https://gadgets.muse.ai/settings/sdk-tokens).
2. На Кубике отсканируйте первый QR, подключитесь к `KUBIK-XXXX`; второй QR открывает
   страницу настройки. Выберите домашнюю сеть 2,4 ГГц, затем **Muse**. Введите SDK key
   в скрытое поле **Muse SDK key** и нажмите **Connect Kubik**. Адрес сервера не нужен.
3. После перезапуска Кубик показывает **Pair Muse on your phone**. Вернитесь на
   обычную сеть телефона. В Muse откройте **Settings → Devices → Developer mode →
   Add device** и выберите `MuseGadget-XXXXXX`, соответствующий Кубику.
4. Разрешите приложению доступ к Bluetooth/устройствам рядом. Когда приложение
   попросит подтверждение, нажмите правую кнопку **KEY** на Кубике. До этого
   нажатия данные аккаунта не принимаются. Выберите Wi-Fi в приложении Muse.
5. После успешной проверки Wi-Fi и сохранения доступа Кубик перезапускается.
   Bluetooth больше не запускается. Дальше используется прямое Wi-Fi-соединение
   с Muse. Нажмите **KEY**, произнесите вопрос и завершите запись; ответ — на экране.

Bluetooth уже встроен в ESP32-C6. Устанавливать Bluetooth на Кубик или подключать
компьютер не нужно. Приложение выдаёт Кубику отдельные device access/refresh tokens:
SDK key разрешает сопряжение, но не заменяет привязку к личному аккаунту.
Поддерживаемый путь авторизации без приложения/Bluetooth в текущем SDK не найден.

## Возможности и ограничения

- Используется голосовая заметка Muse Link: PCM 16 кГц отправляется через
  `POST /chat/stream`, текст приходит через `POST /chat/subscribe` по одному
  TLS/WebSocket/Noise XX соединению. Текст остаётся в контексте Muse.
- На C6 без PSRAM этот путь SDK возвращает **текст**, а не звук. В меню доступны
  STT и информация **Managed by Muse**; TTS, Realtime, GPT Live и выбор модели
  не объявляются доступными. Это не OpenClaw Realtime под другим названием.
- Tess и кнопки сохраняются. На главном экране Tess локальная активация **Hi Tessa**
  доступна при готовом распознавании и соединении. До активации звук не отправляется.
- SDK key и device credentials сохраняются в NVS, не выводятся в config/info,
  журналы и комплект. Полный Reset удаляет их вместе с остальными настройками.
  Текущая сборка не шифрует flash/NVS: физическое чтение flash раскрывает сохранённые
  данные. Не сохраняйте дампы устройства в публичном репозитории.
- Переключение на OpenClaw/Hermes в том же мастере выключает нативный Muse и сохраняет
  его привязку для возвращения. Пустое поле ключа при сохранённом Muse сохраняет
  аккаунт; новый ключ запускает новое сопряжение.
- Пока подтверждённой очереди уведомлений Muse нет, спящий Кубик сохраняет Wi-Fi
  и использует modem sleep. Минутное отключение радио сохраняется для host-агентов.
  Вызов `device.notify` доставляет текст по активной сессии. Доставка через разрыв
  связи и предел задержки облачного Muse на устройстве ещё не подтверждены.
- Поддерживаются официальные `https://api.muse.ai` и `hatch.metaaivm.com`.
  Другие адреса из команды сопряжения отклоняются, а не молча подменяются.

## Обновление и проверка

Bluetooth/Noise увеличили приложение; актуальная разметка — app `0x20000`, размер
`0x300000`, assets `0x320000` для Tess; у Plush app `0x1E0000`, assets `0x200000`,
чтобы сохранить весь набор анимаций. При переходе с прежней разметки обычная запись только
приложения недопустима. Сначала сохраните закрытую резервную копию flash/NVS и
ассетов; используйте полный пакет новой разметки, не стирая NVS. Пакет не содержит
личных ключей. См. [обновление](KIT.ru.md) и [приёмку](acceptance.md).

`python3 tools/test-muse.py` проверяет нативный контракт локально: ввод с телефона,
хранение/выбор аккаунта, ограничения моделей, разбитые контрольные кадры, порядок
статусов и отказ после устаревшей сессии. Штатный upstream harness проверяет настоящее
P-256/AES-GCM, счётчики, повторы, таймауты и физическое подтверждение в программной
модели. Он не доказывает работу BLE-радио, приложения Muse или облака.

## Источники и распространение

Официальный [SDK](https://github.com/facebookincubator/muse-gadget-sdk), revision
`74a5e2d7fc895f109f83a9a1dbed705dbcd8b1ff`; перенесены только Noise core, криптография
сопряжения и C6 chat link. Панель, интерфейс и аппаратный плеер Muse не перенесены.
Apache-2.0 исходников и [условия SDK token](https://gadgets.muse.ai/sdk-terms) — разные
условия. Личный token нельзя встраивать в продаваемую прошивку. Коммерческое
распространение варианта Muse этой реализацией не согласовано.
