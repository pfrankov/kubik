Кубик: прошивка и обновление

Купленный Кубик приходит от продавца уже прошитым. Этот файл нужен, чтобы
обновить прошивку или прошить плату заново. Обновления по Wi-Fi нет: прошивка
обновляется только по USB, как описано ниже.

Полное руководство (выбор сценария, установка плагина, файрвол, экраны,
кнопки, сброс и отзыв устройства) находится в README.md комплекта kubik-kit-tess.zip или kubik-kit-plush.zip.
Здесь только прошивка.

1. Распакуйте ZIP целиком в отдельную папку. Нужна плата Waveshare
   ESP32-C6-Touch-AMOLED-2.16 с флешем 16 МБ и кабель USB-C с передачей данных.
   Драйверы не нужны. На Linux добавьте себя в группу dialout
   (sudo usermod -a -G dialout $USER) и войдите заново.
2. Установите Python 3.7 или новее (рекомендуется свежий 3.x) и создайте окружение:
   macOS/Linux: python3 -m venv .venv && .venv/bin/python -m pip install esptool==4.12.0
   Windows:     py -3 -m venv .venv; .venv\Scripts\python.exe -m pip install esptool==4.12.0
3. Подключите Кубик. Запустите проверку и прошивку из папки ZIP:
   macOS/Linux: .venv/bin/python flash-device.py --check
                .venv/bin/python flash-device.py
   Windows:     .venv\Scripts\python.exe flash-device.py --check
                .venv\Scripts\python.exe flash-device.py
   Если подключено несколько плат Espressif, укажите --port ИМЯ_ПОРТА.
   Скрипт проверяет размеры, расположение и SHA-256 четырёх образов до записи.
   Если esptool видит режим DOWNLOAD, но не получает ответ синхронизации,
   закройте программы, использующие USB-порт, и полностью отсоедините USB-C.
   Если установлена батарея, при отсоединённом кабеле удерживайте PWR до
   выключения, затем удерживайте PWR около 2 с для включения. Затем подключите USB-C
   без удержания BOOT и повторите команду.
   Если после успешной записи экран не запустился, повторите тот же порядок
   перезапуска, включая PWR при батарее.
4. Дальше по README.md комплекта: для Hermes установите платформу внутри его Gateway по docs/hermes.md;
   для собственного ESM-адаптера используйте
   мастер kubik-agent-host и agent-sdk.md. Для OpenClaw установите
   плагин openclaw-kubik-*.tgz на
   компьютер с OpenClaw, подключите Кубик к Wi-Fi с телефона
   (http://192.168.4.1/) и одобрите код с экрана:
   openclaw pairing approve kubik КОД_С_ЭКРАНА

Прошивка не очищает раздел NVS (настройки и ключ Кубика сохраняются).
Не отключайте питание до завершения записи.
Тексты лицензий встроенных компонентов находятся в папке licenses/ этого архива.
