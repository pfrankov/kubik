# Инструкция покупателя и печать

A6, английский текст. Покупатель получает прошитый Кубик; установка агента и
скачивание ПО начинаются со страницы на GitHub. Файлы вместе с устройством
и ссылка из письма или заказа не требуются.

- [START.html](START.html) — единая страница: агент, голос, адрес, Wi-Fi,
  сопряжение, разговор и помощь. Детальные команды раскрываются на месте.
  Готовый запрос агенту находится в разделе [Ask your agent](START.html#assistant).
- [Книжка A6](kubik-getting-started-A6.pdf) — 8 страниц в порядке чтения.
- [Листы A5](kubik-booklet-A5-duplex.pdf) — 4 стороны, 2 листа для сгиба в A6.
- [Редактируемая вёрстка](booklet.html), [стили](booklet.css).
- [Иллюстрации и промпты](illustrations.md).

не установлено: [уведомление](../../licenses/Tessa-model-notice.txt).

## Порядок чтения и стиль

Книжка ведёт через знакомство с кнопками, подготовку агента, два QR,
подключение, сопряжение и разговор. Рецепты OpenClaw/Hermes, выбор голосовых
моделей и варианты сети находятся на одной странице GitHub, а не на отдельных
страницах книжки. Имя персонажа — Tess; точная фраза активации — «Hi Tessa».

Белая бумага, чёрный и тёмно-мятный `#17695F`; существующий PT Sans проекта.
Основной текст 11 pt, внутреннее поле 10 мм. Иллюстрации имеют объёмный ракурс,
выразительный контур, тёмный экран и мятную боковую грань. Кнопки круглые:
BOOT слева, PWR по центру, KEY справа при взгляде на экран. Геометрию схемы
нужно сверить с окончательным корпусом. Схема стоит до первого нажатия кнопки.
QR в книжке — примеры экранов; сканировать нужно коды на самом устройстве.

Экранный Guide не меняется: стрелки BOOT/KEY находятся в верхней строке;
их позиции для подгонки — таблица `anchors` в `guide_button_cue()` файла
`firmware/main/face_agent.c`. PWR в четырёх шагах не объясняется.

## Сборка и проверка

Нужны Google Chrome и uv:

```sh
uv run --with playwright==1.63.0 --with pymupdf==1.26.7 python tools/build-buyer-guide.py
uv run --with playwright==1.63.0 --with pymupdf==1.26.7 python tools/test-buyer-guide.py
```

`print-manifest.json` связывает PDF с текстом, CSS, иллюстрациями, шрифтами и
сборщиком. Приёмка проверяет ссылки, раскрытие подробностей, копирование команд,
вёрстку на телефоне и печать. Чистая установка выполняет основные команды
непосредственно из START.html; русское руководство дополняет обслуживание.

В скачиваемом архиве остаётся копия единой страницы с локальными ресурсами и
шрифтами; Tess также получает Getting-started.pdf. Это содержимое загрузки,
а не обязательные файлы в коробке. Исходники печати остаются в репозитории.

## Как печатать

Для типографии: A6 PDF в порядке чтения, 100% масштаб. Элементы внутри полей,
вылетов нет. RGB-иллюстрации и сглаживание дают визуальную палитру из двух красок
на белом, а не готовые плашечные цветоделения. Их готовит типография.

Для пробы: A5 duplex PDF на бумаге A5 горизонтально, фактический размер,
двусторонняя печать с переворотом по короткому краю, без режима «буклет».
Сложите два листа вместе и согните пополам. Проверьте порядок страниц,
читаемость текста и цвет на выбранной бумаге. Цифровая проверка не заменяет пробу.
