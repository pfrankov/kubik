1 · Choose your agent

Prepare your agent.

  1. Muse: sign in on your phone. Create a personal SDK key using the GitHub guide.
  2. OpenClaw / Hermes: install the agent and Kubik integration. Check a text reply. Keep it running.
  3. Configure speech for OpenClaw/Hermes. Muse voice notes return text.

At home, use the same trusted network. For a remote server, prepare the connection using the GitHub guide first.

Ready: Muse key or agent service running.
Downloads and detailed commands are on GitHub.03

2 · On your phone

Scan both QR codes.

Connect USB-C power. Press PWR to wake the screen; if powered off, hold it for about two seconds.

First: join Kubik’s Wi-Fi

Scan Scan to join Wi-Fi and join KUBIK-XXXX. Stay connected if your phone says “no internet”.

Then: open setup

Wait for the gold title Scan again for setup. Scan the new QR to open the setup page.

Next: “Let’s connect Kubik” opens on your phone.
Example screens. Scan your device’s codes.04

Connect to your agent.

  1. Select your 2.4 GHz Wi-Fi, enter its password and tap Continue to agent.
  2. Choose your agent. Muse: enter its SDK key; no server address is needed.
  3. OpenClaw: at home, leave Server address blank. Remote OpenClaw: enter kubik://PUBLIC-IP:18790. Hermes: enter kubik://HOST:18793; no home relay.
  4. Tap Connect Kubik.

Kubik saves the settings and restarts. Your phone may disconnect from KUBIK-XXXX. Watch Kubik now.

The address belongs to the Kubik integration, not your agent’s dashboard or speech provider. The online guide shows where to find it.

Next: Muse pairs on your phone; OpenClaw/Hermes show a pairing code.
No code? See page 8.05

3 · Confirm the connection

Approve your Kubik.

Muse app: Settings / Devices / Developer mode / Add device. Choose Kubik’s MuseGadget; press KEY when asked, then choose Wi-Fi. Bluetooth turns off afterward.

OpenClaw / Hermes: use the code displayed on your Kubik. For OpenClaw, first match it to the pairing list.

OpenClaw

openclaw pairing list kubik
openclaw pairing approve kubik CODE

Hermes

python ~/.hermes/plugins/kubik/pair.py CODE
Connected: follow Guide; BOOT returns home.
No match? Check the GitHub setup guide.06

4 · On Kubik

Talk to Tess.

Say “Hi Tessa”, then your question.

STT / Classic

Hold KEY, speak, release. Or press once to start, again to send.

Realtime

Press KEY, speak, then pause to send.

GPT Live

Start with KEY or “Hi Tessa”. Speak at Listening, even during replies. KEY ends it; pauses do not.

Voice output + volume 20+: spoken replies. Otherwise: text.
Wake phrase: “Hi Tessa” · Character: Tess07

Settings and help.

Open Settings

Hold BOOT for Settings. Hold volume for Sound: Speech/Interface. Agent → Voice: OpenClaw modes/models. Set Hermes models in Hermes. Guide replays the tour. Short BOOT goes back.

Add a Wi-Fi network

Open Settings → Wi-Fi, then scan both codes again. Known networks are remembered.

Setup page will not open

Stay on KUBIK-XXXX and open http://192.168.4.1/ in your browser.

No pairing code or reply

Keep the agent computer and Kubik service running. Settings → Status shows IP, MAC and server address. See the GitHub setup guide.
