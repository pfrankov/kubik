# Собственные адаптеры и Agent SDK

Связано: [руководство SDK](../agent-sdk.md), [сопряжение](pairing.md),
[установка канала OpenClaw](maintenance.md#mnt-25).

## SDK-01

Действие: В пустом каталоге установить `openclaw-kubik`, не устанавливая OpenClaw.
Импортировать `openclaw-kubik/agent-sdk` в свой ESM-адаптер и вызвать
`npx kubik-agent-host --help`.

Результат: SDK загружается, справка CLI показывает команды настройки и запуска.
Установка и запуск самого OpenClaw не требуются. При установке пакета как канала
в OpenClaw сохраняется штатное сопряжение, включая подтверждение через Telegram.
