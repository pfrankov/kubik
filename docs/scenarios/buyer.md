# Настройка на GitHub и печатная инструкция

Связано: [первый запуск](setup.md), [разговор](conversation.md),
[обслуживание](maintenance.md), [источник инструкции](../buyer/README.md).

## BUY-01

Действие: Покупатель открывает адрес GitHub из печатной книжки.

Результат: На одной английской странице представлены подготовка агента, голос, адрес, Wi-Fi, сопряжение и помощь. ПО скачивается с GitHub отдельно; файлы вместе с Кубиком не требуются. До публикации адрес явно помечен как placeholder, а не рабочая ссылка. Книжка Tess содержит восемь страниц A6.

## BUY-02

Действие: Покупатель без установленного агента открывает START.html и проходит подготовку.

Результат: Он получает ссылку на официальную установку OpenClaw, проверяет текстовый ответ, скачивает интеграцию с GitHub и ставит канал и отдельно настраивает голос. Наличие текстовой подписки не обещает доступ к голосовому API.

## BUY-03

Действие: Покупатель проходит подключение по печатной книжке.

Результат: Первый QR присоединяет телефон к KUBIK-XXXX; второй открывает настройку. После Wi-Fi код появляется при доступном агенте. Книжка показывает ожидаемый результат каждого этапа и путь к помощи.

## BUY-04

Действие: Пользователь выбирает Hermes в веб-мастере.

Результат: Подсказка объясняет установку платформы внутри уже существующего Hermes Gateway и настройку его STT/TTS. Поле адреса раскрыто и требует `kubik://ХОСТ:18793`; отдельный host не предлагается.

## BUY-05

Действие: После соединения пользователь читает подсказку одобрения в веб-мастере, инструкции GitHub или книжке.

Результат: Для OpenClaw и собственного Agent Host подсказка предлагает получить список ожидающих кодов и одобрить только совпадающий код; команды списка и одобрения показаны отдельно. Для Hermes показана команда `plugins/kubik/pair.py` с кодом с экрана Кубика. Во всех случаях пользователь проверяет код перед одобрением.

## BUY-06

Действие: Сопровождающий меняет текст, шрифт, иллюстрацию или вёрстку печатной инструкции.

Результат: Приёмка обнаруживает устаревший PDF. Пересборка проверяет поля, отсутствие обрезанного текста, число и размер страниц, встроенные шрифты и ссылки; листы для сгиба сохраняют порядок чтения.

## BUY-07

Действие: Перед первым нажатием кнопки покупатель смотрит схему в книжке или START.html.

Результат: До первого указания нажать кнопку пользователь видит объёмную схему с тремя круглыми кнопками: BOOT слева, PWR по центру, KEY справа при взгляде на экран. Здесь же объясняются короткое и долгое нажатия BOOT/PWR и назначение KEY; способ отправки голоса описывается после выбора режима.

## BUY-08

Действие: Пользователь читает шаг с двумя сканированиями.

Результат: Две иллюстрации показывают Кубик с крупным QR и подписями Scan to join Wi-Fi / Scan again for setup. Примеры в книжке обозначены как иллюстрации; сканировать нужно коды на самом устройстве.

## BUY-09

Действие: Скачать ПО с GitHub для своего адаптера, открыть agent-sdk.md, перейти по ссылке на протокол или руководство плагина, затем из протокола вернуться по ссылке в Agent SDK.

Результат: Открывается соответствующий документ внутри комплекта; путь не ведёт за пределы распакованной папки.


## BUY-10

Действие: Пользователь открывает раздел Voice на единой странице настройки и раскрывает инструкцию своего агента.

Результат: Для OpenClaw видит Classic STT/TTS, Realtime и GPT Live с настройкой
ключа, профиля и отдельной ссылки TTS; для Hermes — Classic и настройки речи в самом Hermes.
Секреты вводятся локально и не передаются в чат или на Кубик. Проверка
конфигурации не объявляется успешным платным разговором.

## BUY-11

Действие: Пользователь читает раздел Connection address на той же странице и выбирает расположение своего агента.

Результат: Для OpenClaw на общей доверенной сети оставляет Server address пустым.
При заблокированном обнаружении копирует kubik://IP:PORT из статуса его канала.
Для Hermes всегда задаёт `kubik://IP:18793` с IP, доступным из сети Кубика.
Для удалённого OpenClaw использует доступный IP и pinned TLS.
Домен для этих путей не требуется.

## BUY-12

Действие: Пользователь копирует готовый запрос из раздела Ask your agent, добавляет
адрес GitHub, папку скачанного ПО, агент, режим, язык и расположение host.

Результат: Агент с доступом готовит настройки, сохраняя остальное. При отсутствии
доступа предоставляет команды; интерактивный мастер и ввод ключа выполняет
пользователь. Сопряжение одобряется после сверки кода.

## BUY-13

Действие: Пользователь настраивает STT/TTS в Hermes и подключает Кубик к его платформе.

Результат: В Classic используются настройки речи Hermes; ключи остаются на сервере. При Speech ниже 20 или недоступном TTS ответы появляются текстом.

## BUY-14

Действие: Пользователь до первого разговора читает страницу Talk to Tess.

Результат: Персонаж называется Tess, точная фраза активации указана как «Hi Tessa».
KEY остаётся альтернативным способом; для STT/Realtime описана отправка,
для GPT Live — Recording, непрерывный разговор и завершение через KEY.
