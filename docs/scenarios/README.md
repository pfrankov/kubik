# Пользовательские сценарии Кубика

что пользователь делает и какой результат видит. Экран Кубика и веб-настройка — на английском.

Связанные действия используют один контракт: подключение ведёт к гайду и настройкам;
настройки агента задают возможности разговора; сеть и питание определяют доставку;
обновление сохраняет настройки, полный сброс удаляет их.

Каждый ID уникален и сохраняется при уточнении сценария. Новый сценарий добавляют
в подходящую категорию. Каждый файл этого каталога содержит не больше 200 строк.
При изменении поведения одновременно обновляют затронутые сценарии и ссылки,
сверяют связанные категории и проверяют контрастные действия. Старое поведение,
которое пользователь отверг, не возвращают под видом исправления документации.
Исторические замеры хранятся отдельно в [истории](../history/2026-10-02-pre-refactor-scenarios.md).
